# ライブラリとチャットの操作

WindowsとMacで共通です。

- パネルの大きさは右下のつまみで変更します。ヘッダーの小・中・大・特大の選択を廃止しました。
- ライブラリの検索欄をコンパクトにし、操作メニューを1行にまとめました。幅が足りない場合は横へスクロールできます。
- チャット欄の右上の矢印で、会話履歴と入力欄を見出しだけに折りたたみます。同じボタンでもう一度展開できます。下書きと会話を保持し、返信中も処理を続けます。展開すると元の境界位置へ戻ります。
- 素材とチャットの境界にある細い線を上下へドラッグすると、双方の高さを調整できます。位置は保存され、パネル全体の大きさを変えても追従します。入力欄と素材側には最小の高さを確保します。
- 設定のAI・チャット項目にある「Codexにアプリ内の操作をすべて許可」をオンにすると、対応する追加・編集・削除・撮影などを追加確認なしで実行できます。初期状態はオフです。OSのカメラや画面収録の許可は別途必要です。

「ライブラリの内容をすべてゴミ箱に移して」や、検索で特定した素材の削除・復元を依頼できます。削除はライブラリ内のゴミ箱への移動です。原本とお気に入り等を保持し、ゴミ箱から復元できます。一括操作は準備時点の素材を対象とし、その後に追加された素材を含めません。

更新前の会話で「新しい会話を開始してください」と表示された場合は、会話欄左上の＋から新規チャットを開いてください。新しい操作ツールの一覧で会話を開始します。以前の会話は履歴に残ります。

この設定はアプリが提供する操作に適用されます。PC全体の管理者権限や、任意のファイルを永久削除する機能を追加する設定ではありません。[Codex App Serverの公式仕様](https://learn.chatgpt.com/docs/app-server)に従い、アプリ側で操作・確認・結果の読み戻しを行います。
