# Mac開発版665の素材ライブラリ

ローカル開発版の機能。公開macOS版644にはまだ配信していない。Windows 0.2.10と保存形式・一覧UIを共有する。クラウド同期は行わない。

## 保存・整理・表示

上端の機能から「素材」を選ぶ。「ファイル」から取り込み、右クリックするとフォルダ単位でも取り込める。コピーした画像・ファイルはクリップボードのボタンで保存する。原本のコピーを `~/Library/Application Support/HoverPocket/AssetLibrary` に保存する。

- サムネイルのダブルクリック、または選択してSpaceでプレビュー。画像・動画はダブルクリックで一覧へ戻る。
- ⌘クリックで選択を追加・解除、Shiftクリックで範囲選択、空白からのドラッグで矩形選択。
- 名前のダブルクリックで名前変更。星でお気に入り、右クリックで分類・コピー・保存先指定・ごみ箱を選ぶ。
- Delete/Backspaceでライブラリのごみ箱へ移動、⌘Zで元に戻す。文字入力中は素材を削除しない。
- 全画面ボタンまたはCtrl+⌘Fで同じ画面内に拡大。Escで全画面解除、通常プレビューからは一覧へ戻る。
- 画像の編集は同じパネルで行い、ペン・文字・図形・矢印・移動・消しゴムを使える。保存は別画像とし、元画像を保持する。
- 整理画面のサイドバーでフォルダ・タグ・検索条件・復元操作を扱う。

取り出しは原本と独立した作業コピーを渡す。大きいファイルのドラッグでは準備完了後にもう一度ドラッグする。作業コピーは自動消去せず、使い終えた後に整理画面の明示操作でMacのゴミ箱へ移す。

## スクリーンショット・画面収録

素材画面のカメラ/収録ボタン、またはメニューバーから起動する。既定は撮影が⌘⌥S、収録の開始/停止が⌘⌥R。「撮影・収録の設定」で⌘⌥1/⌘⌥2へ切り替えられる。他アプリとの競合時は画面のボタンを使える。

撮影はウィンドウへ重ねてクリック、またはドラッグで範囲を選ぶ。選択枠のそばの操作で、その場所で注釈を書いて保存する。✓、Enter、画像のダブルクリックで保存、×/Escで取消。保存後の画像付き通知は既定5秒、設定範囲は0〜30秒。ホバー・ドラッグ中は時間を止め、通知から作業コピーを渡せる。

663では、別のアプリが前面にある状態でも撮影画面を前面に出し、キー入力を受け取るよう修正した。撮影途中で別アプリへ切り替えても選択画面は保持される。

収録は画面またはウィンドウを選んで開始。システム音・マイクを個別に選べる。最大1920×1080/30fps、H.264/AACのMP4を保存する。停止は同じショートカットまたはメニューバーから行う。素材画面から撮影・収録した場合は、選択中の単一フォルダへ登録する。

画面取得・マイクはmacOSの許可が必要。失敗した撮影は保存待ちフォルダへ保持し、設定の「保存待ちの撮影を再登録」で再試行する。完了ファイルの登録を確認してから保存待ちコピーをMacのゴミ箱へ移す。

## AIから操作する

設定の「音声・AI」でCodex app-serverを選び、音声を開始して依頼する。開発版665では、たとえば次の操作ができる。

- 「今のウィンドウを撮って、資料フォルダへ保存して」
- 「このウィンドウの収録を始めて」「収録を止めて保存して」
- 「最近の画像を探して」「その画像を開いて」
- 「名前を○○にして」「お気に入りに入れて」「資料フォルダに分類して」
- 「○○というフォルダを作って」

対象の名前が曖昧なら候補から指定する。「通常操作を音声で確認」がオンの場合は、対象を確認してから次の発話で承認する。収録停止はすぐに実行する。撮影対象は確認中に別のウィンドウへ切り替わっても変わらない。音声からの収録ではマイクは既定オフで、システム音は撮影設定を引き継ぐ。

画像や動画そのものをAIへ送る機能ではなく、名前や分類などの情報を使って操作する。動画を開くだけでは再生を始めない。画面取得が未許可の場合はmacOSの設定で許可が必要。[操作仕様と検証範囲](../requirement/asset-library-voice.md)。

## バックアップ・復旧

整理画面でmanifestと原本をフォルダへ書き出す。復元先は空のライブラリに限り、schema・参照・SHA-256を検査してから登録する。既存ライブラリへの統合復元は提供しない。

DBスナップショットを戻す際は現在のDBを退避し、原本は保持する。DBを開けない場合も復旧画面からスナップショットを選べる。DBから外れた原本は復旧操作で登録する。「ライブラリのごみ箱を空にする」は原本をMacのゴミ箱へ移し、アプリ内のUndo対象から外す。

## ローカル検査

作業用checkoutで `./script/verify_mac_assets.sh` を実行する。別のBundle ID・Keychain識別子と一時データでビルド・検査し、最後に根拠フォルダを表示する。取得が未許可の場合は撮影・音声の検査をスキップとして記録する。

検査用実行と通常起動を区別する。開発Bundle IDでも、通常起動時の素材保存先は上記の共通ディレクトリであり、別ライブラリにはならない。既存版と同時にライブラリを開こうとした場合は後から開いた側を停止する。

[確認済み項目と未検証の条件](../../progress/2026-10/2026-10-05_hover-pocket-mac-assets.md)を確認してから利用する。
