# Mac・Windowsの素材同期

Eagle Syncと同じく、それぞれの端末で素材を保存し、Syncthingの専用フォルダで原本と変更記録を交換します。Eagleのライブラリや転送フォルダは共有しません。クラウドアカウントは追加しません。

## 接続

1. Syncthingで、MacとWindowsに同じIDのHoverPocket専用共有フォルダを作ります。Eagle用フォルダとは別にします。
2. 一方のHoverPocketの設定から「新しい同期を作る」で空の専用フォルダを選択します。
3. 同期情報が届いたら、もう一方で「既存の同期に参加」から対応するフォルダを選択します。Macでは「設定 → 素材と同期 → 接続の詳細」にあります。

以後は約3秒ごとに変更を確認します。「今すぐ確認」でも処理できます。実際の転送時間は回線・ファイル容量・Syncthingの状態によります。設定の状態表示は届いた記録の処理状況で、相手への転送完了を保証するものではありません。Syncthing側でも転送状況を確認できます。

## 同期する内容

素材の原本、名前、お気に入り、フォルダとタグ、その所属、ゴミ箱への移動と復元を同期します。保存した検索条件、サムネイル等のキャッシュ、アプリ設定、チャット履歴は同期しません。同じ内容の素材は重複して増やさず、それぞれの端末で既存の素材IDを保持します。

オフライン中の変更は端末に残り、再接続後に送信します。受信順が逆になった場合や、大きな原本だけ遅れて到着した場合も、必要な記録が届いてから反映します。

## 同時編集と復元

同じ素材を両方で編集した場合は、現在の内容を保持して設定画面に競合を表示します。内容を比べ、「この端末の内容」または「受信した内容」を選ぶと、その選択を相手にも伝えます。同名フォルダは自動統合しません。名前を調整して受信を再試行できます。

ライブラリのゴミ箱から戻す操作も同期します。「ゴミ箱を空にする」による原本の物理削除は相手へ伝播せず、相手側はゴミ箱移動までです。転送フォルダの原本と履歴は自動削除しません。

「同期を一時停止」では素材や履歴を削除しません。DBスナップショットの復元前には同期を停止し、復元後も停止を維持します。現在の同期履歴は巻き戻しません。破損DBの復旧で履歴を確定できない場合は、自動再開せず照合を案内します。

## コードで端末を接続する（開発版）

MacとWindowsの両方でSyncthingを起動し、HoverPocketの「設定 → 素材と同期」を開きます。片方で「接続コードを表示」を押し、もう片方にコードを入力します。両画面の端末名と確認番号を照合して、コードを表示した側で共有を許可します。接続するとゴミ箱も含むライブラリ全体を共有します。既存のライブラリの接続先は保持します。

コードは5分で失効します。取消、設定ウィンドウを閉じる、アプリ終了でも接続の準備を取り消します。「接続済みの端末」から解除すると、このライブラリの共有だけを止め、受信済みの素材は残します。「接続完了」は端末の登録完了で、素材の転送完了とは別です。

コードの照合には暗号化した端末情報を交換する外部の仲介サービスを利用します。素材はそこへ送信しません。接続元のネットワーク情報と接続時刻は仲介サービスに分かります。詳しい構成は[共通接続処理](../../shared/pairing-helper/README.md)を参照してください。iPhone単体での同期には対応していません。
