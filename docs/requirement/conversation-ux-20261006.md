# 会話とパネル操作の改善（2026-10-06）

WindowsとmacOSの共通仕様。既存の素材・音声接続・権限確認を維持する。

- 会話欄の左上に履歴サイドバーと新規チャットを並べる。左の一覧から既存の会話を再開できる。
- 常設入力欄に送信／停止、音声会話、音声文字起こし、モデル、推論の操作をまとめる。Enterで送信、Shift+Enterで改行し、IMEの確定では送信しない。
- モデルと推論は接続先の `model/list` が返す選択肢を使い、設定を次の送信にも適用する。自動を選ぶと既定値へ戻る。
- 利用可能な操作は通常の文字色で表示する。利用できない操作だけ理由を表示する。待機中の大型案内、M／0、折り畳みボタン、下部の履歴選択を廃止する。
- 推論中／返答中は表示とアニメーションで知らせる。動きを減らす設定を尊重する。
- 入力・返信・音声会話中も、ホバー解除で閉じる。返信を中断せず、会話と下書きを保持する。モデル／推論のメニュー表示中だけ自動収納を止め、選択・取消・フォーカス解除後は通常のホバー収納へ戻る。Windowsの選択肢はパネル内へ収める。範囲選択・設定等の操作画面とサイズ変更中は操作を完了できるよう保持する。
- 設定の「ショートカットキー」でパネル、チャット、ライブラリ、設定、音声、撮影、画面収録、範囲収録を変更できる。Deleteで無効化し、重複・他アプリとの競合は理由を表示して既存設定を保持する。
- 範囲収録は一つの画面の選択範囲だけを保存する。Windowsは画像を切り出してから動画化し、MacはScreenCaptureKitの `sourceRect` を使う。音声設定・停止・ライブラリ保存は既存経路を使う。
- パネル右下のつまみで連続的にサイズを変更し、終了時に保存する。最小は旧Small、最大は旧Extra Largeの縦横約15%増を10単位へ切り上げる。本文とヘッダーの基準寸法はWindowsで520×372〜900×650 DIPs、Macで520×372〜880×630 pt。会話欄・音声欄など必要な高さを加え、表示先画面の作業領域へ収める。既存のサイズボタンを選ぶと手動サイズを解除する。
- ドラッグ中も実際の本文領域の幅・高さに応じて配置を更新する。カレンダーの左右を見やすい幅へ配分し、日付マスの縦横比を固定する。操作カードや電卓などは内容の最大幅・高さを設け、最小サイズで収まらない内容は内部スクロールで操作できるようにする。

## 初期ショートカット

既に保存された撮影／収録キーは引き継ぐ。新しい操作の初期値は以下。

| 操作 | Windows | Mac |
| --- | --- | --- |
| パネル | Ctrl+Alt+H | Cmd+Alt+P |
| チャット | Ctrl+Alt+C | Cmd+Alt+C |
| ライブラリ | Ctrl+Alt+L | Cmd+Alt+L |
| 設定 | Ctrl+Alt+O | Cmd+Alt+O |
| 音声会話 | Ctrl+Alt+V | Cmd+Alt+V |
| 撮影 | Ctrl+Alt+S | Cmd+Alt+S |
| 画面収録 | Ctrl+Alt+R | Cmd+Alt+R |
| 範囲収録 | Ctrl+Alt+Shift+G | Cmd+Alt+G |

WindowsのHとShift+Gは実環境の既存アプリとの競合を避けるために採用した。

## 利用上の制約

現在のChatGPTログイン経路は音声文字起こし専用に対応していないため、ボタンを理由付きで無効にする。従量課金APIへ自動切り替えしない。[OpenAIのプレビュー制約](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)を参照。

Macの画面収録にはOSの許可が必要。未許可時は開始せず理由を返す。今回の実録画検証はその許可待ち。[検証記録](../../progress/2026-10/2026-10-06_hover-pocket-conversation-ux.md)を参照。
