# AI Usage: 一覧とメーターの表示（2026-11-19、ユーザー承認済みのデザイン）

> 2026-11-19 夕方の改訂（ユーザー承認済み）: 「サブスクの利用枠」と「クレジット・残高」のセクション分け（2.9）、数字の書体（2.10）、並び替えをブラウザ標準のドラッグからポインタ操作へ変更（2.7）。

Windows版とmacOS版のAI Usageパネルの見た目と操作の正本。2026-11-19にユーザーとモックアップで決めた。取得の仕組み（各サービスの読み方、古い値・エラーの判定、再取得のきっかけ）は変えない。

## 1. 目的

今の表示は、カードごとの「HH:mm 更新」、2行に折り返すリセットの文、プラン名、使用率と残高の混在で、ぱっと見でごちゃついている。ひと目で「どの枠があとどれだけ残っているか」が分かるようにし、並び替えもできるようにする。

## 2. 共通の決まり

### 2.1 数字は「残り」

- パネルの数字は、どの枠も残りの割合にする。残り = 100 − 使用率。表示は今の書式と同じで、整数ならそのまま、そうでなければ小数1桁（例: `21%`、`94.9%`）。
- 棒とメーターの弧も残りの分だけ埋める（燃料計と同じ向き）。
- 値のない枠（`state = unreadable`）は数字を出さず「取得できません」とし、色も付けない。0%や100%として描かない。

### 2.2 色（残りの割合で決める。凡例は出さない）

| 残り | 色 |
|---|---|
| 70%以上 | 青 `#5aa9ff` |
| 50%以上 | 緑 `#5fd08a` |
| 25%以上 | 黄 `#f5c35b` |
| 25%未満 | 赤 `#ff7c7c` |

数字の文字色、棒、メーターの弧に使う。今の「80%以上で黄、90%以上で赤」（使用率の基準）は廃止する。

### 2.3 見出し（パネル上部）

- 左から: タイトル「AI Usage」、表示の切り替え（`一覧` / `メーター` の2つの区切りボタン）、右端に「HH:mm 更新」を1回だけ、更新ボタン。
- 「HH:mm 更新」は、表示中のサービスのうち状態が `ok` のものの取得時刻で最も新しいもの。`ok` が1つもなければ出さない。
- 更新中は「更新中…」。

### 2.4 カードから外すもの

- カードごとの「HH:mm 更新」（見出しの1回に集約）。
- プラン名のバッジ（Pro Lite、Max 5x など）。プラン名は設定のAIの状態表示に残る。
- Antigravityのモデル名（設定のAIの状態表示に残る）。
- 「経過NN%」の文と、棒の上の経過位置の縦線。

### 2.5 リセットまでの時間（短い書き方）

- 24時間未満: `4:49`（時:分、分は2桁）。1時間未満は `0:35`。
- 24時間以上: `3日21時間`（時間が0なら `3日`）。
- 過ぎていたら `リセット済み`。不明なら何も出さない。
- 正確な日時（例: `11/23(月) 11:00にリセット`）はマウスを乗せたときのヒント（Windowsは `title`、macOSは `.help`）で出す。
- 英語表示では `4:49`、`3d 21h`、`Reset`、ヒントは `Resets Mon 11/23 11:00`。

### 2.6 古い値・エラー・未サインイン（判定は今のまま、出し方だけ変える）

- 古い値（`stale`）: その行・そのまとまりの数字と棒・弧だけを薄くし（不透明度0.5前後。枠の名前とリセットまでの文字は薄くしない）、名前の下（メーターは名前の横）に黄色で `13:20 の値` と出す。理由（今のエラー文）は、一覧ではその行の数字の欄の下に（左端を `5時間` の列にそろえ、右端は行の端まで）、メーターでは名前の下に出し、2行まで折り返す（省略記号で切らない）。「更新」とは書かない。
- 表示中に期限（`freshUntil`）を過ぎた値も同じ扱い（今の仕組みのまま。`freshUntil` を持たないサービスには期限を作らない。取得から時間がたっただけで薄くしない）。
- 値のないエラー: 数字の欄をまとめて、理由を行の幅いっぱいで出し、2行まで折り返す。
- 未サインイン: 数字の欄をまとめて「サインインしていません」と「設定を開く」。「設定を開く」はボタンかリンクと分かる見た目にする（説明の文と同じ見た目にしない）。Colabの共有サインインの文言は今のまま。

### 2.7 並び順（両方の表示で共通）

- 順番はセクションごとに別々に設定へ保存する（どちらもサービスIDの配列）: `サブスクの利用枠` の順（今の「自分の順」）と、`クレジット・残高` の順。片方を動かしても、もう片方の順は変わらない。初期値は今の順。知らないIDは捨て、配列にない新しいサービスは末尾に足す。非表示のサービスも順番は保持する。
- パネルで、取っ手（縦の点6つのアイコン）をつかんで動かすと、同じセクションの中で並べ替わる。一覧では行、メーターではまとまり、残高ではカードを動かす。ほかのセクションへは移せない。
- 並べ替えは、ポインタの操作（押す・動かす・離す）で行う。ブラウザやOSの標準のドラッグ＆ドロップは使わない（暗い透明な窓では、ドラッグ中の画像が大きな黒い四角として出て、落とす先も働かなかったため）。押している間は、つかんだ項目を浮かせて（縁を `#5aa9ff`）、ほかの項目がその場で入れ替わる。離した時点で保存する。Escか、窓の外で離したときは元の順に戻す。
- 取っ手にはキーボードでも届き、取っ手を選んで矢印キー（上下・左右）で1つずつ動かせる。支援技術向けの名前は「<サービス名>を移動」。
- 設定の「AI」→「AI使用状況」の一覧も同じ順に並べ、各行の右上（表示のスイッチの左）に小さなアイコンのボタン（上向き・下向きの矢印）を付ける。支援技術向けの名前は「上へ」「下へ」。サインインのボタンとは並べない。先頭の「上へ」と末尾の「下へ」は薄くし、押しても何も起きない。
- パネルのスクロールバーは見せない（スクロールはできる）。

### 2.8 覚えておくもの

- 表示の種類（`list` / `meter`、初期値 `list`）、2つのセクションそれぞれの順番、一覧の並び替えの状態（列と向き、または「自分の順」）を設定に保存し、次に開いたときも同じにする。一覧の列による並び替えは `サブスクの利用枠` だけに効く。

### 2.9 セクション（両方の表示で共通）

- パネルの中身を2つのセクションに分け、それぞれ見出しを付ける: `サブスクの利用枠`（使用率の枠を持つサービス）と `クレジット・残高`（残高を持つサービス）。見出しは小さな文字（12px、`#9ba6b5`）と、右へ伸びる細い線（`rgba(255,255,255,.08)`）。
- 両方を持つサービス（Codex）は、両方のセクションに1つずつ出る。Codexのクレジットは、利用枠のまとまりや行には入れない。
- 未サインイン・値のないエラー・読み込み中のサービスは、本来の欄が分かればそのセクション（残高だけのサービスは `クレジット・残高`）、分からなければ `サブスクの利用枠` に出す。
- どちらかのセクションが空なら、そのセクションの見出しも出さない。
- 一覧では、表のあとに `クレジット・残高` の見出しを置き、その下に残高のカードを並べる。メーターでは、利用枠のまとまりのあとに同じ見出しと残高のカードを並べる。

### 2.10 数字の書体

- 数字（残りの割合、リセットまでの時間、残高、見出しの更新時刻）は、Apple風の書体にする。Windowsはアプリに同梱した Inter（`windows/ui/fonts/InterVariable.woff2`、SIL Open Font License 1.1、許諾書は `ThirdParty/Inter-LICENSE.txt`）、macOSはシステムの書体（SF Pro）。
- 数字の幅はそろえる（Windowsは `font-feature-settings: "tnum"`、macOSは `monospacedDigit()`）。字間は大きな数字で少し詰める（-0.02em 相当）。太さは中程度（500）。等幅の書体（Consolasなど）は使わない。
- 単位（`%`、`CR`、`CU`）は数字より小さく薄い色（`#9ba6b5`）にする。`$` は数字と同じ大きさのまま。
- 日本語の文字は今のままの書体。

## 3. 一覧（list）

### 3.1 形

- 行 = サービス、列 = 取っ手 / サービス名 / `5時間` / `1週間` / `別枠`。列の見出しの行は、下へ送っても上に残す。
- 各セル: 1行目に左「残りの数字」（13px、色は2.2）、右「リセットまで」（11px、薄い色）。2行目に高さ5pxの棒（残りの分を2.2の色で埋める）。
- `別枠` のセル: 1行目の左を `Fable 24%` のように「枠の名前（薄い色）＋数字」にし、右にリセットまでを出す（名前と時間を両立させる）。別枠が2つ以上あるサービスは、同じセルの中に縦に積む。
- どの列に入れるか: 名前のない5時間（`kind = session`、`windowMinutes = 300`）→ `5時間`。名前のない1週間（`kind = weekly`）→ `1週間`。名前のある枠と、それ以外の長さの枠 → `別枠`（名前のない枠は長さ「3日」などを名前にする）。その枠がないセルは `—`。
- 見出し行: サービス名の列は、並び替えをしていないときは薄い文字で `残り`、並び替え中は `自分の順に戻す` のボタン。`5時間`・`1週間`・`別枠` は押せる見出しで、右に向きの矢印を出す（並び替えに使っていない列は上下の矢印を薄く）。
- 一覧の行は、枠を1つ以上持つサービスと、理由を出す必要があるサービス（未サインイン、値のないエラー、読み込み中）だけ。状態が `ok` で残高しかないサービス（Claude API、Colab）は行にせず、札だけにする。
- 枠の名前が長いとき（例: `GPT-5.3-Codex-Spark`）は省略記号で切り、完全な名前はヒントで出す。同じ名前の枠が2つ以上あるときは、名前の後ろに長さを付けて区別する（例: `Spark 5時間`、`Spark 1週間`）。
- 数字とリセットまでの時間は重ねない（あいだに最低6px）。入らないときは時間を棒の下の行へ回す。
- 残高（Claude ConsoleのAPIクレジット、Codexのクレジット、Colabのユニット）は、表のあとの `クレジット・残高` セクションに、メーターと同じ残高のカード（4.1）で並べる。Claude APIは同じサービスの残高の合計を出し、内訳と期限はヒントで出す。`unlimited` は `無制限`、`unreadable` は `読み取れません`。

### 3.2 並び替え

- 列の見出しを1回押すと、その列の残りが少ない順（上限に近い順）。もう1回押すと多い順。以後は押すたびに入れ替わる。
- 別の列の見出しを押すと、その列の少ない順から始める。
- `別枠` はセルの中で最も残りが少ない枠の値で比べる。
- その列に値のないサービス（`—`、取得できない、エラー、未サインイン）は、どちらの向きでも末尾に置き、その中は自分の順。
- 値が同じときは自分の順。
- 並び替え中は取っ手を出さない（ドラッグは自分の順のときだけ）。
- 見出しは押せる要素にし、並び替えの状態を支援技術に伝える（Windowsは `aria-sort`、macOSはアクセシビリティの値）。

## 4. メーター（meter）

### 4.1 まとまり

- サービスごとに1つのまとまり（角丸の枠）。上に名前と取っ手、下にメーターを横に並べる。枠が複数あるサービスは、車の計器のようにメーターを横に並べる（例: Claudeは `5時間`・`1週間`・`Fable` の3つ）。並べる順は 5時間 → 1週間 → 別枠。
- まとまりは横に流し、入りきらなければ次の行へ回す。パネルが狭くてもメーター自体は縮めない。
- 残高は `クレジット・残高` セクションのカードで出す（一覧と共通）: 1行目に取っ手とサービス名（`Claude API`、`Codex クレジット`、`Colab`。12px、`#9ba6b5`）、2行目に大きな数字（約27px、2.10の書体）と小さな単位（`40,957.15 CR`、`$104.98`、`570.2 CU`）、3行目に補足（期限 `12/12まで`、Codexは `サブスクの枠を超えた分に使う`、Colabは今の消費の文）。カードの最小幅は約170px。

### 4.2 メーター1つの描き方（116×100の枠、中心(58,54)）

- 弧: 下を開けた270度（左下 135° から時計回りに右下 405° まで）。半径46、太さ5の暗い溝（`#161b22`）。
- 外側の帯: 半径51、太さ1.6の細い帯を4区間に分け、2.2の4色を不透明度0.45で塗る（0〜25 赤、25〜50 黄、50〜70 緑、70〜100 青）。区間の境目は少し空ける。
- 目盛り: 5%ごとの細い線（半径39.5〜42、`#343b46`）、25%ごとは少し長く明るい線（半径37.5〜42、`#8a94a6`）。**数字は付けない。**
- 値: 残りの分だけ、溝の上に同じ太さで2.2の色の弧を、短い区切りの点線（2.6と1.3の繰り返し）で重ねる。
- 針: 値の位置に白い短い線（半径37〜52、太さ2、端は丸）。
- 中央: 上に小さく `残り`（11px、`#697386`）、その下に大きな数字（約23px、2.2の色、2.10の書体）と小さな `%`。
- 下の切れ目: 1行目に枠の名前（`5時間`、`1週間`、`Fable`。11px、`#9ba6b5`）、2行目にリセットまで（11px、`#697386`）。1行目は弧の端より上にあり幅が狭いので、切れ目の幅（約60px）に収め、超える分は省略記号にする。2行目は弧の端より下なのでメーターの幅まで使える。同じ名前の枠が2つ以上あるときは、1行目は名前だけにし、長さは2行目の先頭に付ける（例: 1行目 `GPT-5.3-Co…`、2行目 `5時間 · 2:00`）。完全な名前はヒントと支援技術向けの名前に入れる。
- 取得できない枠: 値の弧と針を描かず、中央は `—`、下の切れ目は名前だけ（リセットまでの行は出さない。同じ名前の枠が2つ以上あるときは2行目に長さだけを出す）。「取得できません」はヒントと支援技術向けの名前で伝える。
- 古い値: 数字・値の弧・針だけを薄くし、枠の名前とリセットまでの文字は薄くしない（2.6）。
- 光彩・影・グラデーションは使わない。背景はパネルの面の色のまま。
- 支援技術向けの名前: `1週間 残り21%、あと3日21時間でリセット`。

## 6. 受入条件

1. 一覧とメーターを見出しで切り替えられ、次に開いたときも同じ表示になる。
2. 数字・棒・弧が残りの割合で、色が2.2の4段階になる。凡例はない。
3. 一覧の列の見出しを押すたびに、少ない順と多い順が入れ替わる。値のないサービスは常に末尾。「自分の順に戻す」で戻る。
4. 取っ手のドラッグと、設定の上へ・下へで順番を変えられ、両方の表示と設定の一覧が同じ順になる。再起動後も保たれる。
5. 別枠のセルに枠の名前とリセットまでの時間が両方出る。
6. カードごとの更新時刻、プラン名、モデル名、経過の文が出ない。更新時刻は見出しに1回。
7. 古い値・エラー・未サインイン・値のない枠を、0%・100%・「更新」と見せず、今と同じ理由を出す。
8. 横にはみ出さない（パネルの幅を最小にしても横のスクロールが出ない）。
9. 既存の検証が通り、上の1〜8を確かめる検証を足す。
10. `サブスクの利用枠` と `クレジット・残高` のセクションに分かれ、Codexのクレジットは利用枠のまとまりに入らない。片方の順番を変えても、もう片方は変わらない。
11. 実際のマウスで取っ手をつかんで動かすと並べ替わり、画面が暗くならない。キーボードの矢印でも動かせる。
12. 数字が2.10の書体で、等幅の書体を使っていない。
