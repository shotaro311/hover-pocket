# Mac素材ライブラリ Windows 0.2.10対応表

基準: Windows `a02eb9f`、機能 `eba3774`。Mac開発ビルド662。Windowsの一覧UI・検証fixture・保存契約を共有し、保存・メディア・撮影・注釈・ドラッグをMacのAPIへ接続した。液体アニメーション等の既存変更を引き継いだ。同期、公開配信は対象外。

| 対象 | Mac実装 | 検証 |
| --- | --- | --- |
| schema1、NFKC/full case fold、原本コピー、重複、再開 | SQLite actor、共有SQL/正規化表、SHA-256と処理記録 | 保存検査・別プロセス再開が通過。実強制終了・ディスク満杯は未検証 |
| 分類、検索v1/v2、お気に入り、ごみ箱、Undo、バックアップ | 共有UIとMac保存処理、空ライブラリへ復元、破損DB・孤立原本の復旧 | Windows fixture復元→再出力、改ざん拒否・破損DB保持を確認。両OS実機往復は未検証 |
| Cmd/Shift/矩形選択、名前変更、星、右クリック、フッター | Windows一覧UIを同梱。Macは⌘表記 | 共通JS45項目をWKWebViewで通過 |
| 画像/動画/PDF、ズーム、全画面、終了競合 | ImageIO/PDFKit/AVFoundation、同じプレーヤーを拡大 | 再生・シーク・PDF2ページ・全画面復帰・90ms後の停止、上端パネル20回切替を確認。4K・混在DPIは未検証 |
| 同一パネル注釈、保存/取消/失敗再試行 | 7種類の操作、色・線幅、Undo/Redo、コピー保存 | 原寸・描画画素・原本保持・再試行・取消を確認 |
| 撮影対象強調、範囲指定、その場で注釈 | ScreenCaptureKitの静止画と対象枠、選択箇所の注釈・保存 | 実ウィンドウのPNGと向きを確認。全手動選択・通知操作は未受入 |
| 画面/窓の収録、システム音/マイク、停止保存 | H.264/AAC、マイク合成、保存待ち再試行 | 動画と音声3モードの短い実収録が通過。長時間同期・デバイス切断は未検証 |
| 通知、停止タイマー、作業コピーのファイルD&D | 0〜30秒（既定5秒）、ホバー/ドラッグ停止、NSURL copy操作 | コピー独立性・隔離属性を確認。自動マウスは準備通知まで。外部ドロップ成功・通知D&Dは未受入 |
| 既存クリップボード、設定、起動、データ保持 | 既存の液体アニメーション差分を引継ぎ、隔離データで検証 | clipboard/timer/panel-layout、100回panel-soakが通過。元checkout2,099ファイルのSHA一致 |
| Retina/複数画面/許可/ちらつき | 同じ画面内に展開、取得許可と失敗表示 | このMacのRetina画面を確認。複数画面、拒否操作、最低基準実機、連続フレームのちらつき受入は残る |

既存変更のバックアップ: 元checkoutの `work/mac-asset-library-20261005-baseline/`。2,099ファイルをアーカイブからSHA-256で再検証済み。
