# Mac / Windowsの責務整理

2026-10-05のユーザー依頼: 両OSのHoverPocketをリファクタリングし、WindowsはWindows側Codexに依頼する。検証後にコミット・プッシュする。

## 変更範囲

- Macは既存の `codex/macos-asset-library-0210` を使用。前回の素材機能と引き継いだアニメーションを土台コミットへ保存し、責務整理の差分を別コミットにする。
- Macの対象は表示先画面の選択、パネル負荷検査の計測、素材のWebView/ドラッグ、DB行から素材への変換。画面の優先順位と代替先、ドラッグの終了処理、原本・保存契約を保つ。
- Windowsは既存チャット「スクリーンショット時のクラッシュ修正」へ依頼。Windows専用作業ブランチで保存・検索/分類/復旧、動画部分配信と終了処理を整理する。Mac側からWindowsコードを並行編集しない。
- 機能追加・依存追加・同期・公開リリース・本番アプリ置換・mainへの直接反映は今回の変更に含めない。既存の未コミット作業と個人データを保持する。

## 受入

- 各OSのビルド、関係する既存CLI/ネイティブ検査が通る。
- Macでは素材保存/UI/再開、パネルレイアウト/クリップボード/タイマー/100回検査、画面選択とアニメーションの実行経路を確認する。
- DBの不正な行を安全に拒否し、原本を保持する検査を追加する。既存の互換fixtureと整理前の出力を比較する。
- 保存形式・DB版・公開バージョンの変更を行わない。移動した処理は元ソースと照合し、既存ファイルもSHAでreadbackする。
- OS別ブランチへコミット・プッシュし、リモートcommitを別経路で照合する。未検証の物理条件は引き続き明記する。
